# BAIRGS Boutique Clothing

## About the Project

BAIRGS Boutique Clothing is a clothing website created for my WEDE Part 1 project at Rosebank College. The website is designed for customers between the ages of 18 and 34 who are interested in fashionable and affordable clothing.

The website provides information about the boutique, its products and services, and ways for customers to make enquiries and contact the business.

## Website Pages

- **Home** – Introduction to BAIRGS Boutique.
- **About Us** – Information about the boutique.
- **Services/Products** – Displays the clothing products available.
- **Inquiry** – Allows customers to make an enquiry.
- **Contact Us** – Provides contact information for the boutique.

## Technologies Used

- HTML5
- CSS3

## Project Features

- Easy-to-use navigation
- Product information
- Contact and enquiry sections
- Responsive website design
- Clean and simple layout

## Target Audience

The website is aimed at customers aged 18–34 who are interested in trendy, affordable and quality fashion.
